# Cancel all open Binance Futures algo orders

Cancel all open Binance Futures algo orders

## Usage

``` r
futures_cancel_all_algo_orders(symbol, config = config_futures())
```

## Arguments

- symbol:

  Trading pair symbol.

- config:

  A futures configuration created by
  [`config_futures()`](https://oliverlds.github.io/binxr/reference/config_futures.md).

## Value

A parsed list.
