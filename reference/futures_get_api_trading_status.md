# Get Binance Futures API trading status

Get Binance Futures API trading status

## Usage

``` r
futures_get_api_trading_status(symbol = NULL, config = config_futures())
```

## Arguments

- symbol:

  Optional trading pair symbol.

- config:

  A futures configuration created by
  [`config_futures()`](https://oliverlds.github.io/binxr/reference/config_futures.md).

## Value

A parsed list.
