# Cancel multiple Binance Options orders

Cancel multiple Binance Options orders

## Usage

``` r
options_cancel_batch_orders(order_ids, config = config_options())
```

## Arguments

- order_ids:

  A non-empty numeric vector of exchange order IDs.

- config:

  An options configuration created by
  [`config_options()`](https://oliverlds.github.io/binxr/reference/config_options.md).

## Value

A parsed list.
