# Start a Binance Options user data stream

Start a Binance Options user data stream

## Usage

``` r
options_start_user_data_stream(config = config_options())
```

## Arguments

- config:

  An options configuration created by
  [`config_options()`](https://oliverlds.github.io/binxr/reference/config_options.md)
  with an API key.

## Value

A parsed list containing a listen key.
